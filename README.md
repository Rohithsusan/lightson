# LIGHTSON PHOTOGRAPHY

> We don’t just capture moments. We make them last.

Cinematic portfolio website for **LIGHTSON PHOTOGRAPHY** — covering weddings, pre-wedding sessions, portraits, events, and commercial brand photography.

## Features

- **Cinematic Visual Experience**: Interactive lighting aesthetics, lens-flare animations, film-grain texture, and smooth transitions.
- **Curated Gallery & Filters**: Category-based portfolio filtering (Weddings, Pre-Wedding, Maternity, Portraits, Events, Commercial).
- **Interactive Lightbox**: Full-resolution preview with ambient flare effects.
- **Featured Film Reel**: Horizontal scroll showcase highlighting standout frames.
- **Enquiry Form**: Direct booking/contact section.
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
